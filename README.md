# Earbud Explorer

A responsive, dependency-free comparison dashboard for nine premium Bluetooth earbuds, designed for iPhone and desktop.

## Features

- Swipe or slide between earbuds
- Seven visual performance metrics
- Adjustable weights and recalculated rankings
- Full comparison table and CSV export
- Indicative Australian pricing

## Run

Open `index.html` in a browser. To publish the website, enable GitHub Pages under **Settings → Pages → Deploy from a branch → main → / (root)**.

## Data disclaimer

Figures reflect a user-supplied comparison dated 30 Oct 2026. Prices are indicative and scores are provisional editorial assessments, not verified laboratory results. Battery estimates mix measured, claimed and provisional values.
